## TaskFlow Lite — Capability Classification

| # | Capability                     | Classification    | Value                                                                                  |
| - | ------------------------------ | ----------------- | -------------------------------------------------------------------------------------- |
| 1 | Register tasks                 | Essential for MVP | Allows users to capture tasks in a centralized place instead of scattered records.     |
| 2 | View registered tasks          | Essential for MVP | Gives team members visibility into the tasks that have been recorded.                  |
| 3 | Update task information        | Essential for MVP | Keeps task details accurate as work requirements change.                               |
| 4 | Update task status             | Essential for MVP | Helps users identify the current progress of each task.                                |
| 5 | Persist tasks between sessions | Essential for MVP | Ensures registered tasks and changes remain available after reloading the application. |
| 6 | Delete tasks                   | Posterior         | Allows users to remove tasks that are no longer needed.                                |
| 7 | Search and filter tasks        | Posterior         | Helps users locate specific tasks as the task list grows.                              |
| 8 | Assign tasks to team members   | Posterior         | Makes responsibility for individual tasks visible across the team.                     |

MVP scope: Capabilities 1–5 establish the minimum functionality required to register, visualize, update, and retain task information in alignment with the Product Goal.

Posterior scope: Capabilities 6–8 can be considered after validating the core task-tracking workflow with users.
